# 01. Как делать заплатки (remedy)

## Когда нужен remedy

Когда нужно **изменить существующий файл проекта** (например добавить новую вкладку в office_ui.py), но файл большой, сложный, и менять его руками — риск сломать работающее. Remedy — это маленький скрипт который сам находит нужные строки и правит их.

## Когда НЕ нужен remedy

- Создать новый файл → просто создай руками
- Удалить файл → просто удали
- Изменить одну строчку → открой файл Блокнотом и исправь

## Структура remedy-файла

Каждый remedy:
1. Имя: `remedyNN.py` где NN — номер (10, 11, 12...)
2. Читает исходный файл в строку `s`
3. Ищет точную строку которую нужно заменить (`old = "..."`)
4. Заменяет на новую (`new = "..."`)
5. Пишет обратно
6. Печатает отчёт о каждой правке

## Пошаговая инструкция (как ИИ пишет remedy)

**1. Найти точный маркер.**
Открой файл в Блокноте → Ctrl+F → найди строку которую надо изменить → скопируй её **дословно** со всеми пробелами и кавычками.

**2. Написать remedy.**
Шаблон:

```python
report = []
p = "имя_файла.py"
s = open(p, encoding="utf-8").read()

old = "точная строка из файла"
new = "новая строка вместо неё"

if old in s:
    s = s.replace(old, new)
    report.append("ПРАВКА 1: OK")
elif new in s:
    report.append("ПРАВКА 1: уже применена")
else:
    report.append("ПРАВКА 1: СТОП - маркер не найден")

open(p, "w", encoding="utf-8").write(s)
print("=== ОТЧЁТ REMEDY ===")
for r in report:
    print("  " + r)
