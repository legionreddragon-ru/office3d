- Числа с точкой Excel показывает как текст и не суммирует
- Даты превратились в непонятные числа

## Три кита русского CSV (выучить наизусть)

1. **Разделитель — точка с запятой «;»**
   Русский Excel ждёт «;», потому что в региональных настройках РФ
   разделитель списков = «;». Запятая как разделитель = одна колонка.

2. **Кодировка UTF-8 с BOM**
   Файл начинается с невидимых байтов \ufeff. Без них Excel не поймёт
   что это UTF-8, и русский станет кракозябрами.

3. **Десятичный разделитель — запятая**
   В РФ дробные числа пишутся через запятую: 394,50 а не 394.50.
   Точка = Excel посчитает число текстом, суммы не соберутся.

## Эталонный код создания CSV (копировать в новые отчёты)

```python
lines = ["Дата;Тип;Категория;Сумма;Описание"]
for t in transactions:
    summa = str(t["amount"]).replace(".", ",")
    lines.append(t["date"] + ";" + t["kind"] + ";" + t["category"] + ";" + summa + ";" + t["note"].replace(";", ","))
txt = "\ufeff" + "\n".join(lines) + "\n"
with open(path, "w", encoding="utf-8") as f:
    f.write(txt)
