# 📚 SKILLS (чек-листы процедур офиса)

Здесь живут инструкции для офиса и для тебя. Когда ИИ забывает как что-то делать — открывай нужный файл.

## Оглавление

- [01-remedy.md](01-remedy.md) — Как делать заплатки (remedy)
- [02-streamlit-widgets.md](02-streamlit-widgets.md) — Как лечить Streamlit-виджеты
- [03-csv-russian.md](03-csv-russian.md) — Как работать с CSV в русском Excel

## Как использовать

**Для ИИ:** в новом чате вставь содержимое нужного файла первым сообщением, потом задачу.

**Для тебя:** когда что-то сломалось — открой нужный файл, следуй чек-листу.

## Когда добавлять новый файл

Когда ты или ИИ решили проблему, которая заняла больше 30 минут — запиши процедуру сюда. Через месяц у тебя будет база знаний на все случаи жизни.
