# ВИДЕНИЕ ПРОЕКТА ОФИС-3D

## Миссия
Создать **автономную систему управления жизнью** — цифровой помощник, который освобождает время семьи для главного: здоровья, отношений, развития детей, творчества.

## Два уровня проекта

### Уровень 1: Офис-3D (сейчас)
**Назначение:** пробник технологии + возможный источник заработка
**Что делает:**
- Учитывает финансы (чеки → база → отчёты в Excel)
- Ведёт склад (пластик, изделия, принтеры, пробники)
- Создаёт контент для VK (посты, напоминания, ярмарки)
- Планирует закупки (анализ остатков, поиск лучших цен)
- Помогает на ярмарках (ROI, статистика продаж)

**Бизнес-модель:**
- Продажа лицензии малым производствам 3D-печати (15 000₽ + 1 500₽/мес)
- Мульти-тенантность на одном VPS (Docker-контейнеры для клиентов)
- Гибридная модель: лёгкие задачи локально, тяжёлые через российские API (YandexGPT, GigaChat)

**Статус:** пробник работает, готов к масштабированию (Этап 2-7 в плане)

### Уровень 2: Семейный помощник (главная цель)
**Назначение:** универсальный ассистент для всей семьи
**Что будет делать:**
- **Быт:** напоминания (оплатить коммуналку, купить продукты, ТО машины), учёт расходов по категориям
- **Здоровье:** календарь врачей, напоминания о прививках, учёт лекарств
- **Образование детей:** планирование занятий, контроль домашки, подбор курсов
- **Дом:** интеграция с умным домом (свет, отопление, безопасность через Home Assistant)
- **Финансы семьи:** общий бюджет, цели (отпуск, ремонт), инвестиции
- **Автономность:** офлайн-библиотека (Kiwix + DevDocs), свои модели ИИ, независимость от чужих серверов

**Принципы:**
- **Приватность:** все данные хранятся локально, ничего не уходит в облако без необходимости
- **Надёжность:** работает даже при отключении интернета (офлайн-режим)
- **Устойчивость:** бэкапы на свой сервер, защита от сбоев чужих сервисов
- **Масштабируемость:** от одного пользователя (семья) до бизнеса (офис-3D для клиентов)

## Техническая основа
- **Ядро:** мульти-агентная система (12 ролей + оркестратор Павел)
- **Модели:** локальные LLM через Ollama (qwen2.5:7b, phi3:mini, deepseek-r1:7b)
- **Хранение:** SQLite (структурированные данные) + JSON (доска объявлений)
- **Интерфейс:** Streamlit (веб-панель) + Telegram-бот (мобильный доступ)
- **Автономность:** локальная обработка, офлайн-режим, свои бэкапы

## Философия
> "Цель технологии — не заменить человека, а освободить его для того, что важно."

Офис не принимает решения ЗА семью — он **предлагает варианты**, **напоминает**, **анализирует**. Финальное решение всегда за человеком.

## Дорожная карта
1. **Сейчас:** Офис-3D как пробник (финансы, склад, контент)
2. **Через 6 месяцев:** добавление семейных модулей (быт, здоровье, образование)
3. **Через 1 год:** интеграция с умным домом, полная автономность
4. **Через 2 года:** продажа лицензии другим семьям (как альтернатива дорогим SaaS)

## Метрики успеха
- **Время:** сколько часов в неделю освобождается для семьи (цель: 10+ часов)
- **Деньги:** сколько экономится на автоматизации (цель: 5 000+ ₽/мес)
- **Спокойствие:** меньше забытых дел, меньше стресса
- **Заработок:** доход от продажи лицензии (бонус, не главная цель)

## Главное правило
> "Сначала семья, потом бизнес. Офис-3D — это инструмент для достижения свободы, а не самоцель."
